How it works

◎

Scan

Every skill file and every MCP config — launch command, endpoint, env-var names. 60+ local patterns; optional Cisco, Snyk, SkillAudit.

⛨

Block

A PreToolUse hook refuses unscanned skills and flags risky MCP tools before they run. Modified since last scan? Blocked until you re-scan.

◇

Audit

Local by default. Every pattern is readable source. Secrets are detected in memory only — never written to cache or history. False positives: one --mark-fp.

FAQ

What does it scan?
Claude Code skills (SKILL.md and bundled scripts) and every MCP server in your config — global, project, and plugin .mcp.json files.
Does it block MCP tool calls?
Yes, when mcp_policy is enforce (the default): unscanned or flagged MCP servers are refused at the PreToolUse gate, same as skills.
Are API keys stored?
No — env and header values are scanned in memory for inline secrets, then redacted; only variable names persist.
What detection engines?
local is stdlib-only and instant; add cisco, snyk, or skillaudit when you want a second opinion. Missing deps skip gracefully.
Install without the plugin?
curl -fsSL https://skillguard.sh/install | sh or pip install -e . from a clone — then wire the hook in settings.json.
