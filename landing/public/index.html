Shut the gate

Leave no secrets

Local by default. Your files stay on your machine unless you opt into a cloud engine. API keys get caught in RAM, redacted, forgotten — never written to cache or SQLite. False positive? --mark-fp once, move on.

Before you install

What's in the blast radius?
Every Claude Code skill (SKILL.md + bundled scripts) and every MCP server — global, project, and plugin .mcp.json files. If Claude can invoke it, SkillGuard reads it first.
MCP too, or just skills?
Both. With mcp_policy: enforce (default), a sketchy MCP server hits the same PreToolUse wall as a bad skill. No side door.
Where do my API keys end up?
Nowhere permanent. Values are scanned in memory, redacted on sight — only variable names ever touch cache or history.
What runs under the hood?
local is stdlib-only and instant. Bolt on cisco, snyk, or skillaudit if you want a second opinion. Missing optional deps just skip — no drama.
Not using the plugin marketplace?
curl -fsSL https://skillguard.sh/install | sh or pip install -e . from a clone. Wire the hook in settings.json and you're gated.
Can I ship this in a product?
Community build is AGPL-3.0. Commercial licenses exist if copyleft doesn't fit your release.
