How it works.

1

Check skills, bundled files, and MCP server config with local or optional engines.

2

At runtime, use cached verdicts. Block unknown, changed, critical, and high-risk targets unless allowed.

3

Keep history and hook decisions local. Inspect secrets in memory; persist only redacted records.

FAQ.

What does it check?
Agent skills, bundled files, and MCP server surfaces from global, project, and plugin config.
Does it block MCP calls?
Yes. mcp_policy defaults to enforce, so unknown or critical/high MCP servers are refused.
Do API keys touch disk?
No. Env and header values are inspected in memory, then redacted before records persist.
What leaves my machine?
Nothing with the local engine. Files leave only when you enable an optional cloud engine.
Prefer the Claude Code plugin?
Inside Claude Code, run /plugin marketplace add mannanj/skillguard and then /plugin install skillguard@skillguard.
