Block unsafe skills before they run.

Gandalf checks Claude Code skills and MCP servers before runtime, then blocks anything unscanned, changed, corrupted, critical, or high-risk.

Shell

FAQ

What does Gandalf check?
Skills, bundled files, MCP server config, launch commands, endpoint metadata, and env/header names.
Does it block MCP calls?
Yes. MCP enforcement defaults on, so unknown or critical/high MCP servers are refused.
Do secret values touch disk?
No. Gandalf inspects env and header values in memory, then persists redacted records.
What leaves my machine?
Nothing with the local engine. Files leave only when you enable an optional cloud engine.
What happens when code changes?
The cached verdict no longer matches. Runtime stops until the changed target clears again.
