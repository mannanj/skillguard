Mechanism

Read. Gate. Log.

1

Read

Scan SKILL.md, scripts, MCP configs, launch commands, endpoints, and env/header names.

2

Gate

Block unscanned, changed, critical, and high-risk targets unless you bypass explicitly.

3

Log

Keep local history. Inspect secrets in memory, then redact before persistence.

Details

Short answers.

What gets scanned?
Claude Code skills, bundled scripts, and MCP server surfaces from global, project, and plugin config.
Does it block MCP calls?
Yes. mcp_policy defaults to enforce, so unscanned or critical/high MCP servers are refused.
Do API keys touch disk?
No. Env and header values are inspected in memory, then redacted before records persist.
What leaves my machine?
Nothing with the local engine. Files leave only when you enable an optional cloud engine.
Prefer the Claude Code plugin?
Inside Claude Code, run /plugin marketplace add mannanj/skillguard and then /plugin install skillguard@skillguard.
