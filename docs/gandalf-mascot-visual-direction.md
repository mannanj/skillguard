# Gandalf Mascot Visual Direction

Date: 2026-06-17

Status: design context for the landing-page mascot and future character work.

## Current Ask

The app mascot should move away from a face-only mark and toward a clearer
Gandalf-style wizard guard: top half of the body, long beard, pointed hat,
glasses, robe shoulders, and staff.

The desired rendering is a black-and-white cartoon sticker with a clear,
steady, thick white outer outline around the full silhouette. The outline should
read like a die-cut sticker, not a blur or glow.

User direction allows explicit Gandalf parody/lore likeness. Rights clearance is
handled outside this repo.

## Acceptance Notes

- Top-half body must be visible; avoid a face-only crop.
- Long beard should be prominent and Gandalf-like.
- Hat should read as a wizard hat at landing-page size.
- Keep the outside white outline thick, distinct, and mostly even.
- Prefer black, white, charcoal, and soft greys; staff may use muted wood.
- Avoid extra background scenery in the logo mark.
- Preserve readability at the mobile hero size.

## Future Companion Note

The two-wizard contrast reference can support a future feature idea: Gandalf
invites or unlocks a friend/companion character for an expanded security feature
set. The contrast should communicate "main guard plus specialist companion"
rather than adding a second character to the main logo.
