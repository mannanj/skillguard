# Task: Gandalf Mascot Redesign

**Status:** draft v2 wired into landing page; pending visual review.
**Created:** 2026-06-17

## Goal

Improve the app's main Gandalf mascot so it reads as a clear Gandalf-style
wizard guard instead of a face-heavy mark.

## Direction

- Use an explicit Gandalf parody/lore-likeness direction.
- Show the top half of the body, including robe shoulders and a long beard.
- Include a readable wizard hat, glasses, and staff.
- Match the target sticker style: a clear, thick, steady white outer outline.
- Keep the mark compact enough for the landing-page hero and social previews.

Rights and launch clearance are handled outside this repo.
